**Ticket Management API**

A robust RESTful API built with Spring Boot for managing support tickets. It features secure JWT-based authentication, role-based access control, pagination, sorting, and full OpenAPI/Swagger documentation.

**Features**

Secure Authentication & Authorization: Stateless user authentication using JSON Web Tokens (JWT) integrated with Spring Security.

Ticket Management: Create, read, update, and delete (CRUD) support tickets with full validation.

Pagination & Sorting: Efficiently query large datasets using Spring Data Pageable.

API Documentation: Interactive documentation powered by Springdoc OpenAPI / Swagger UI.

**Tech Stack**

Java (17 or higher)

Spring Boot

Spring Security (JWT)

Spring Data JPA (Hibernate)

Database: MySQL / PostgreSQL (configure your preference in application.properties)

Maven for dependency management
